# VelQuery

Query-first SQL execution engine for .NET 10: correct async semantics, source-generated typed mapping,
compile-time SQL diagnostics, and transparent benchmarks. Not an ORM.

> Status: pre-alpha (v0.1 in progress). Nothing here is production-ready, and no performance claims are made yet.

See [docs/prd/VelQuery_PRD_v1.0.md](docs/prd/VelQuery_PRD_v1.0.md) for requirements and [AGENTS.md](AGENTS.md)
for repository conventions.
